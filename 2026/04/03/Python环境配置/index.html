Python环境配置

一、Anaconda 安装教程（Windows/Mac/Linux 通用）

Anaconda 是数据科学领域常用的环境管理工具，包含 Conda 包管理器、Python 解释器及大量预装科学计算库，推荐新手直接安装完整版（而非 Miniconda）。

1. 下载安装包

  • 官网地址：Anaconda 官方下载

  • 版本选择：根据操作系统（Windows/Mac/Linux）和系统位数（32/64 位）选择对应安装包（建议选 Python 3.9+ 版本，兼容性更强）

  • 国内镜像（推荐，下载更快）：清华大学开源镜像站

2. 安装步骤（以 Windows 为例，Mac/Linux 类似）

  1. 双击安装包，点击「Next」→ 勾选「I Agree」

  2. 选择安装类型：

  • 个人使用选「Just Me」（推荐，无需管理员权限）

  • 多用户共享选「All Users」（需管理员权限）

  1. 选择安装路径：
  • 建议自定义路径（如 D:\Anaconda3），避免中文路径和空格（否则后续可能报错）
  1. 高级选项（关键！）：

  • 勾选「Add Anaconda3 to my PATH environment variable」（自动配置环境变量，新手必选）

  • 勾选「Register Anaconda3 as my default Python 3.9」（设为默认 Python 解释器）

  • 点击「Install」，等待安装完成（约 5-10 分钟）

  1. 完成后取消勾选「Learn more about Anaconda Cloud」，点击「Finish」

四、Conda 核心命令（环境与包管理）

Conda 最强大的功能是隔离环境管理，可避免不同项目的依赖冲突。

1. 环境管理

命令用途 命令代码
创建新环境（指定 Python 版本） conda create -n env_name python=3.10 （env_name 为环境名）
激活环境 Windows：conda activate env_name；Mac/Linux：source activate env_name
退出环境 conda deactivate
查看所有环境 conda env list 或 conda info --envs
复制环境 conda create -n new_env --clone old_env
删除环境 conda remove -n env_name --all

2. 包管理（激活环境后使用）

命令用途 命令代码
安装包 conda install package_name （如 conda install pandas）
安装指定版本的包 conda install package_name=1.5.3
安装多个包 conda install package1 package2 package3
卸载包 conda remove package_name
更新包 conda update package_name
更新所有包 conda update --all
查看已安装的包 conda list
搜索可安装的包 conda search package_name
